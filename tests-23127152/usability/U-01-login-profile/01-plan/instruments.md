## 1. SUS (System Usability Scale)

Thang Likert **1–5** (1 = Hoàn toàn không đồng ý, 5 = Hoàn toàn đồng ý).

| # | Nội dung item | Điểm (1–5) |
|---|---------------|------------|
| 1 | Tôi nghĩ tôi sẽ muốn dùng hệ thống này thường xuyên. | |
| 2 | Tôi thấy hệ thống này phức tạp một cách không cần thiết. | |
| 3 | Tôi thấy hệ thống này dễ sử dụng. | |
| 4 | Tôi nghĩ mình cần người rành kỹ thuật hỗ trợ mới dùng được hệ thống này. | |
| 5 | Tôi thấy các chức năng trong hệ thống này được tích hợp tốt với nhau. | |
| 6 | Tôi thấy hệ thống này có quá nhiều điểm thiếu nhất quán. | |
| 7 | Tôi nghĩ hầu hết mọi người sẽ học cách dùng hệ thống này rất nhanh. | |
| 8 | Tôi thấy hệ thống này rất cồng kềnh, bất tiện khi dùng. | |
| 9 | Tôi cảm thấy rất tự tin khi dùng hệ thống này. | |
| 10 | Tôi cần học nhiều thứ trước khi có thể bắt đầu dùng hệ thống này. | |

**Công thức** (tính ở Phase 3):

- Item lẻ (1,3,5,7,9): đóng góp = (điểm chọn) − 1  
- Item chẵn (2,4,6,8,10): đóng góp = 5 − (điểm chọn)  
- Tổng đóng góp (0–40) × 2.5 = điểm SUS (0–100)

| Khoảng | Xếp loại |
|--------|----------|
| > 85 | A — Tuyệt vời |
| 73–85 | B — Tốt |
| 52–72 | C — Trung bình |
| < 51 | D/F — Kém |

## 2. Probe questions (mở)

Hỏi sau SUS. Giọng trung lập. Mỗi nhóm hỏi ít nhất câu (a); câu (b) nếu còn thời gian.

| Nhóm | Câu hỏi |
|------|---------|
| **Clarity** | (a) Khi bạn cần đăng nhập và cập nhật hồ sơ, bước nào bạn thấy khó hiểu nhất? Vì sao? |
| | (b) Trên trang hồ sơ, thông tin hiển thị có đủ để bạn biết mình đang sửa đúng chỗ không? |
| **Error recovery** | (a) Nếu lúc nãy bạn nhập sai hoặc hệ thống báo lỗi, bạn có biết cách sửa và làm tiếp không? |
| | (b) Có lúc nào bạn nghĩ mình vừa bấm nhầm không? Bạn đã làm gì tiếp theo? |
| **Speed** | (a) Từ lúc bắt đầu đến lúc bạn thấy đã cập nhật xong, bạn thấy nhanh hay chậm hơn bạn hình dung? |
| | (b) Có bước nào bạn cảm thấy phải làm lại hoặc chờ đợi không cần thiết không? |
| **Trust** | (a) Sau khi bấm cập nhật, bạn có tin hồ sơ đã được lưu đúng không? Dựa vào tín hiệu nào? |
| | (b) Nếu đây là địa chỉ và số điện thoại thật của bạn, bạn có yên tâm dùng quy trình này không? Vì sao? |
