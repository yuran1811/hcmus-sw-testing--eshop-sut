# AI-02 - Faculty template map

Source: `[AI-02] - FIT@HCMUS - AI Audit Report_En` (course AI Policy Templates 2026 v1.0).

## Sections the grader expects

1. **Student Information** - name, ID, class, assignment ID, date, tools, Yes/No AI
2. **Instructions** - one row per artifact; verbatim prompt/output; VALID/INVALID/INCOMPLETE
3. **Audit Table** - five columns:

| Col | Content |
| --- | --- |
| (1) Prompt + Tool | Tool name, time `HH:MM dd/mm/yyyy`, full prompt |
| (2) AI Output | Full output or labelled screenshot/file |
| (3) Verdict | VALID / INVALID / INCOMPLETE |
| (4) Reasoning | Cite course slide, ISTQB section, or technical RFC |
| (5) Student Fix | Corrected artifact; highlight change |

4. **Summary of AI Accuracy** - counts + % for VALID / INVALID / INCOMPLETE
5. **Conclusion** - 80-150 words on when to use AI
6. **Mandatory Disclosure** - adapted verbatim-style statement
7. **Signature** + references list

## Verdict quick test

- Student changed anything material? -> not VALID
- Output unusable / wrong technique? -> INVALID
- Draft kept after edits? -> INCOMPLETE
