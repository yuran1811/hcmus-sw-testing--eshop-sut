# AI Usage Guidelines - short form (FIT@HCMUS Software Testing)

## Core principles

| Principle | Practice in the audit |
| --- | --- |
| Transparency | Log tool, time, prompt, output for every artifact |
| Understanding | Student can defend every AI-assisted line orally |
| No blind copy | Student Fix / Human Review required |
| Integrity | Verify against SUT, SRS, ISTQB - AI is not ground truth |

## Allowed (typical)

- Research, structure drafts, checklists, analysis scaffolding
- Debug test ideas, format Markdown/Excel
- Draft agent skills the student then runs and corrects

## Not allowed / high risk

- Submit raw AI output without review
- Fabricate experimental results, participants, or screenshots
- Copy prompts between students (shared prompts can zero both parties)
- Use AI for homework-prohibited evidence (see each HW anti-cheat list)

## HW03 prohibited (must not be AI-generated)

- List of 7 participants (name + masked contact)
- Cross-platform screenshots with student email/ID overlay as fake evidence
- Impersonated usability sessions

## Missing AI appendix

Missing required AI declaration / audit / critique can zero related scores or the whole submission depending on HW rules. Always ship Markdown (+ PDF when required).
