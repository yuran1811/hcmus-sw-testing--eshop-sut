## 2. API Selection

| Pool | Feature | Endpoint(s) | Rationale |
|------|---------|-------------|-----------|
| A | FR-05 Product listing & search | `GET /api/products` | Public API; domain partitions trên `search`; bề mặt SEC-05 SQLi |
| B | FR-11 Order history + detail | `GET /api/orders/my-orders`, `GET /api/orders/:id` | Cặp JWT vs no-auth; kiểm IDOR / ownership / PII |
| C | FR-15 Product management CRUD | `POST/PUT/DELETE /api/products` | Admin CRUD theo spec; SEC-02/SEC-03 |
