# Task 3 — Cross-Browser / Cross-Platform Testing

Thư mục này là khu vực thực hiện và quản lý toàn bộ tài liệu kiểm thử tương thích trình duyệt và đa nền tảng (Task 3) cho dự án EShop SUT.

## Cấu trúc thư mục

Các đợt đánh giá được tổ chức theo từng thư mục định dạng `CP-XYZ` (ví dụ: `CP-001`) tương ứng với các luồng nghiệp vụ hoặc cấu hình kiểm thử khác nhau.

- **[CP-001](./CP-001/)**: Đợt kiểm thử tương thích trên 3 trình duyệt (Chrome, Firefox, Safari) sử dụng bộ checklist chung để so sánh và đối chiếu kết quả hiển thị trên các lõi render khác nhau (Chromium, Gecko, WebKit).
