# TC-CART-010: Bấm "Tiếp tục mua sắm" → điều hướng về trang chủ

**Requirement ID:** FR-07
**Test Type:** Domain Testing

### 1. Preconditions

- Người dùng đang ở trang Giỏ hàng (giỏ có thể có hoặc không có sản phẩm).

### 2. Test Data (Inputs)

- Hành động: Bấm nút "Tiếp tục mua sắm"

### 3. Test Steps

1. Mở trang Giỏ hàng.
2. Bấm nút "Tiếp tục mua sắm".

### 4. Expected Result

- Hệ thống điều hướng người dùng quay về trang chủ.
