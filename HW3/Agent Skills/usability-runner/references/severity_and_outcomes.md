# Outcomes and severity

## Session outcomes

| Code | Meaning |
| --- | --- |
| SUCCESS_UNASSISTED | Completed all success criteria without help |
| SUCCESS_ASSISTED | Completed only after moderator intervention |
| FAIL | Could not complete within rules |
| ABANDONED | Stopped early |

## Severity (class mini-exercise)

| Level | Meaning | Typical evidence |
| --- | --- | --- |
| S1 | Cannot complete task | FAIL / ABANDONED due to issue |
| S2 | Needs help or major mistake | SUCCESS_ASSISTED or severe wrong turn |
| S3 | Slow / much hesitation | hesitations, long time, confusion quotes |
| S4 | Minor annoyance | small visual/label issues, recovered fast |

## Frequency

Report as `k/7` participants showing the issue (or `k/n` if pilot-only).
