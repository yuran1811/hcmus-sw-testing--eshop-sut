# Báo cáo Issue

Thư mục này lưu các bản ghi vấn đề hiệu năng được rút ra từ các artifact chạy chính thức của workflow `checkout-with-coupon`.

Hiện có:

- `ISSUE-CWC-001.md`

Mục đích:

- lưu lại bằng chứng phía bài nộp về các vấn đề hiệu năng đã quan sát được
- chuẩn bị sẵn nội dung để đưa lên GitHub Issues nếu cần
- tránh khẳng định quá mức rằng đó là bug chắc chắn khi evidence hiện tại mới chỉ đủ mạnh ở mức quan sát hiệu năng
